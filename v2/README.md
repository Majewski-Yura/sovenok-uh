# Топоух 2

[Открыть версию 2](https://majewski-yura.github.io/sovenok-uh/v2/)

Клуб, «Кругосветка» Топы, 91 интерактивный мини-урок и 12 мини-игр. Три игры в «Минуте игры» меняются каждый день.

Это отдельная сборка. Прогресс версии 1 не импортируется, семейная синхронизация отключена. Статические иллюстрации берутся из общей папки `img/` сайта. Для запуска локально используйте статический HTTP-сервер из корня репозитория.
